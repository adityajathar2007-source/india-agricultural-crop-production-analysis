# 🇮🇳 India's Agricultural Crop Production Analysis

## 📊 Project Overview

India's Agricultural Crop Production Analysis is a data visualization project developed using Tableau Public to analyse agricultural production patterns across India.

The project transforms agricultural data into interactive visualizations, dashboards, and a data story that make it easier to understand crop production, seasonal patterns, state-wise differences, cultivated area, and production trends over time.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyse agricultural production across Indian states.
- Identify major crops based on total production.
- Compare agricultural production across different seasons.
- Analyse year-wise agricultural production trends.
- Visualize state-wise agricultural production geographically.
- Compare cultivated area across states and crops.
- Identify leading states by agricultural production.
- Analyse agricultural yield trends.
- Present the findings through an interactive Tableau Dashboard and Story.

---

## 🛠️ Technologies & Tools

- Tableau Public – Data visualization and dashboard development
- CSV Dataset – Agricultural crop production data
- Microsoft Word – Project documentation
- GitHub – Source code and project documentation hosting
