# in India's Agricultural Crop Production Analysis

## 📊 Project Overview

India's Agricultural Crop Production Analysis is a data visualization project developed using Tableau Public to analyse agricultural production patterns across India.

The project transforms agricultural data into interactive visualizations, dashboards, and a data story that make it easier to understand crop production, seasonal patterns, state-wise differences, cultivated area, and production trends over time.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyse agricultural production across Indian states.
- Identify major crops based on total production.
- Compare agricultural production across different seasons.
- Analyse year-wise agricultural production trends.
- Visualize state-wise agricultural production geographically.
- Compare cultivated area across states and crops.
- Identify leading states by agricultural production.
- Analyse agricultural yield trends.
- Present the findings through an interactive Tableau Dashboard and Story.

### 📊 Dashboard

The Tableau Dashboard provides an interactive overview of India's agricultural crop production, including KPIs, crop-wise production, season-wise analysis, state-wise comparisons, geographic distribution, and year-wise trends.

👉 [View Tableau Dashboard](https://public.tableau.com/app/profile/aditya.jathar/viz/India_Agricultural_Crop_Production_Analysis_Final_1/IndiasAgriculturalCropProductionAnalysis?publish=yes)

---

### 📖 Story

The Tableau Story presents the project findings through a sequence of six story points:

1. Agricultural Overview
2. Geographic Distribution of Agricultural Production
3. Crop-wise Agricultural Production Analysis
4. Season-wise Agricultural Production Analysis
5. State-wise Agricultural Production Comparison
6. Year-wise Agricultural Production Trend

👉 [View Tableau Story](https://public.tableau.com/app/profile/aditya.jathar/viz/India_Agricultural_Crop_Production_Analysis_Final_1/Story1?publish=yes)
